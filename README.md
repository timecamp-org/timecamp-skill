# TimeCamp Skill

Skill to track time spent on tasks using TimeCamp or analysis.

Requirements:
- Python 3.6+ 
- UV
- TimeCamp API key as environment variable `TIMECAMP_API_KEY`
- DuckDB for data analysis

## Installation

To install the skill, run the following command:

```bash
npx skills add https://github.com/timecamp-org/timecamp-skill/skills --skill timecamp
```
